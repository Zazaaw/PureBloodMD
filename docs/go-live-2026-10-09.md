## 3. Fixed during this audit
1. `fix(security)`: `is_blocked_pair(a, b)` let **anyone** check whether doctor A blocked doctor B. Members now use `is_blocked_with(other)`, which only answers about themselves; signed-out visitors can't call member-only helpers (migration 0016).
2. `fix(triage)`: nearest-first radar + Indonesia-wide fallback instead of an empty deck.
3. `fix(triage)`: deck re-fetched right after a scan (no false "no doctors" flash).
4. `fix(ui)`: long names and hospitals wrap instead of "Dr. Smoke ad…" (profile page, chat header).

## 6. What happens after launch, and how to fix it

| Risk | Trigger | What users see | How to detect | Fix | Prevention |
|---|---|---|---|---|---|
| Thin deck outside Jabodetabek | Demo doctors all in Jabodetabek | Nearest doctor is hundreds of km away | Users outside Jakarta complain | Spread demo doctors over more cities, or seed per city | Invite real doctors city by city |
| Bot sign-ups | Test CAPTCHA key | Spam profiles, junk reports | Admin → Users: sudden jump in "New this week" | Swap to real keys (section 5), ban via /admin | Real keys + Supabase Auth CAPTCHA |
| Free-tier limits | Growth | Slow pages, realtime drops, uploads failing | Supabase usage page (egress 5 GB, DB 500 MB, storage 1 GB, ~200 realtime connections) | Upgrade to Pro | Watch usage weekly in the first month |
| Heavier triage on mobile data | All 483 profiles sent per visit | Slow first load on 3G | Vercel analytics / user reports | Paginate `get_candidates` | Do it before the roster grows past ~2,000 |
| Email in spam | New sending domain | "I never got the email" | Resend dashboard | Ask users to check Spam; add DMARC `p=quarantine` later | Warm up the domain, keep content consistent |
| Moderation backlog | Reports / verifications pile up | Waiting > 3 days for the badge | Admin overview queue counts | Add more admins in /admin/settings | Check the desk daily |

**Rollback:** each fix is its own commit (`47fc7f7`, `87ea82a`, `e3fefbb`, `461b386`) and can be reverted alone. Migration 0016 only changes permissions; undo by granting `is_blocked_pair` back. Emails already sent cannot be recalled.
